# cyberpunk — 赛博朋克

灰暗而密集的城市表面钉满霓虹。建筑本体只是拥挤堆叠的廉价混凝土盒子，真正可见的是附着在立面上的招牌、电缆、风管和发光色彩。一切都竖向、潮湿、过度拥挤；灯光承担全部表现，建筑只是它背后的暗色幕布。

## 材料
- **基础结构**：gray_concrete、black_concrete、polished_blackstone、deepslate_bricks——刻意灰暗
- **霓虹**：任意明亮混凝土或 glazed_terracotta，背后放 glowstone 或 sea_lantern；主色为洋红、青、紫和红
- **玻璃**：tinted_glass、black_stained_glass、light_blue_stained_glass
- **杂物**：iron_bars、chain、hopper、item_frame 招牌、旗帜悬挂广告、scaffolding
- **照明**：sea_lantern、glowstone、redstone_lamp、shroomlight——大量、有色，绝不用纯白
- **湿地面**：black_concrete、polished_blackstone，并加入水洼

## 比例
- 塔楼高度为底宽的 5–12 倍，相邻塔楼只留 2–4 格
- 招牌和霓虹覆盖可见立面的 0.3–0.5
- 街道上空在多个高度跨越天桥、管道和电缆
- 街面黑暗狭窄，天空只剩一条缝

## 标志手法
- **灰色上的霓虹**——建筑暗淡、招牌鲜艳；结构必须低饱和，色彩才突出
- **竖向密度**——堆叠、悬挑并连接塔楼，直到街上几乎看不见天空
- **电缆与风管蔓延**——锁链和栏杆在不同高度跨楼连接
- **全息招牌**——大块彩色平板凸出墙面，背后发光

## 变体
- **街面**——市场摊位、雨水、拥挤巷道和食物铺
- **企业塔楼**——更干净、整体性强，只有一个巨型标志
- **贫民堆栈**——集装箱住宅附着在结构框架上
- **屋顶**——天线、空调机组、俯视霓虹和停机坪

## 避免
- 温暖日光；此风格属于夜晚
- 干净无杂物的立面
- 任何历史式装饰
