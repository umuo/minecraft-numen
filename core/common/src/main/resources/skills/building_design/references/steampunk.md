# steampunk — 蒸汽朋克

将机械设备暴露在外的维多利亚砖建筑。管道、锅炉、仪表和齿轮被安装在原本普通建筑的外部，并穿过墙体；铜材随处可见，因为它会氧化成其他材料难以获得的绿色。一切都应显得是后来加装的——机器晚于建筑出现，而且从未被整理隐藏。

## 材料
- **主体**：bricks、deepslate_bricks、polished_blackstone、dark_oak_planks
- **金属**：copper_block 及其所有风化阶段、oxidized_copper、cut_copper_stairs——铜是标志材料，应遍布各处
- **管道与框架**：iron_bars、chain、iron_block、lightning_rod、hopper、cauldron、blast_furnace
- **玻璃**：小型近圆形舷窗使用 tinted_glass、brown_stained_glass
- **照明**：lantern、redstone_lamp，以及通过烟囱排气的 campfire
- **仪表与齿轮**：item_frame 中放 compass 或 clock，也可用 note_block、observer

## 比例
- 竖向且繁杂：使用塔楼和烟囱，而非狭长低矮体量
- 烟囱与管道高度为屋顶高度的 1.5–2 倍
- 机械设备覆盖可见立面的 0.2–0.4
- 窗户小而近圆，开在砖墙中

## 标志性手法
- **外露管线**——iron_bars 与 chain 沿外墙攀升、绕过转角并钻入墙体。越像后期加装，效果越好。
- **铜材遍布**——穹顶、檐沟、锅炉外壳都混用不同风化阶段，一部分明亮，一部分变绿。
- **锅炉与烟囱**——粗大的铜圆筒连接高烟囱，底部可见火焰。
- **铆钉带**——沿金属接缝排列 button 或小方块。

## 变体
- **飞艇码头**——系留塔、栈桥，头顶悬着气囊
- **工坊**——室内杂乱、齿轮转动，每面墙都挂满工具
- **钟楼**——砖塔、巨大铜制钟面和外露机械装置
- **工厂城镇**——多座烟囱，建筑之间由管道跨接

## 避免
- 干净极简的表面
- concrete 或大面积平板玻璃等现代材料
- 将机械设备藏在室内
